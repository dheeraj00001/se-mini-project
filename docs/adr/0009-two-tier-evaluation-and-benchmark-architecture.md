# Two-Tier Evaluation and Benchmark Architecture

Validating hallucination detection and mitigation requires isolating retrieval performance from NLI classification, preventing optimistic calibration overfitting, and integrating automated CI/CD checks. We decided on a two-tier evaluation architecture: Tier A executes ~50 synthetic end-to-end regression test cases via `pytest` in GitHub Actions CI covering the full lifecycle (Ingestion, Retrieval, Verification, Mitigation, Re-verification); Tier B evaluates empirical performance on FEVER (mapping directly to 3-way Supported/Refuted/NotEnoughInfo states) and HaluEval. Retrieval is measured separately using Recall@K and MRR, while NLI thresholds are calibrated on dedicated disjoint splits to compute unbiased Precision, Recall, F1, Confusion Matrix, and ROC-AUC metrics.
